# Freeform Facial Features

Also FFF for short is not a professionally coined term and simply an umbrella term I came up with for heavily stylized facial features that work independently from the head's topology.

The Term as well as the system is heavily inspired by Disney's [_Detached Facial Features_](https://dl.acm.org/doi/pdf/10.1145/3587421.3595414){ target="_blank" } but since SMIRK also makes use of pure "face carving" and other techniques independent of DFF's SDFs, I felt like it's own, similar term to be fitting.
