# Freeform Facial Features

Also FFF for short is not a professionally coined term and simply an umbrella term I came up with for heavily stylized facial features that work independently from the head's topology.

The Term as well as the system is heavily inspired by Disney's [_Detached Facial Features_](https://dl.acm.org/doi/pdf/10.1145/3587421.3595414){ target="_blank" } but since SMIRK also makes use of pure "face carving" and other techniques independent of DFF's SDFs (Signed Distance Fields used to create transitions), I felt like a separate, more broad term was necessary.

Right now I think there are 3 main "categories" of Freeform Facial Features you can build using SMIRK, though experimentation is very encouraged!
